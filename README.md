# Приложения для BMW iDrive — на русском

Коллекция приложений для **MGU Store** с русской локализацией: полезные функции для автомобиля, дополнительные показания и настройка интерфейса.

## Что есть в каталоге

- Настройка подсветки салона и управление сиденьями.
- Видеорегистратор и просмотр камер.
- Оформление приборной панели и виджеты проекционного дисплея.
- Показания автомобиля, чтение ошибок и информация об обслуживании.
- Замеры разгона, торможения и мощности.
- Информация об аккумуляторах и работе гибридной системы.
- Предупреждения о дорожных камерах и другие приложения.

## Язык и совместимость

В каталоге доступны приложения с русским интерфейсом. В приложениях с автоматическим выбором языка он меняется вслед за языком головного устройства. Если нужный перевод отсутствует, используется английский.

Поддержка **iDrive 7 / iDrive 8** указана в карточке каждого приложения. Доступность отдельных функций зависит от модели и оснащения автомобиля.

## Где найти

Приложения доступны в **MGU Store** из источника **DarkMuse1/idrive7-apps-ru**. Описание, совместимость и доступные обновления можно посмотреть прямо в Магазине.

В каталоге представлены работы [cauliflowermossgrape](https://github.com/cauliflowermossgrape/idrive7-apps), [IterioDev](https://github.com/IterioDev/car-apps), [bimmer-lab](https://github.com/bimmer-lab/apps), [eroobeeroo](https://github.com/eroobeeroo/idrive7-cluster-info) и [skalitov-bit](https://github.com/skalitov-bit/bmwcaminfo).
